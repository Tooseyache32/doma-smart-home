# Проверка DOMA

## Автоматические проверки

- `npm install`: успешно, 212 пакетов; npm audit — 0 найденных уязвимостей на момент установки.
- `npm test`: начальная версия — 16/16 успешно. После дополнительных проверок безопасности и совместимости suite расширяется; окончательный результат записан ниже после финального прогона.
- `npm run build`: TypeScript и Vite успешно; первоначальное предупреждение о JS bundle >500 kB потребовало разделения страниц.
- Реальная интеграция API через Vite proxy: обнаружен и исправлен Origin mismatch (явно `changeOrigin:false`).
- Старая development-БД: обнаружена и исправлена миграция сессий при переходе от открытого CSRF к хешу, с отзывом старых сессий без потери бизнес-данных.
- Read-only security review выявил production reuse известных development-паролей и async password-reset races; backend исправлен с защитой startup и повторной проверкой актуальных credentials/session/role.

## Браузер: начальный функциональный прогон

Подготовка: сервер разработки запущен штатной командой, схема и виртуальный дом созданы seed. Вход выполнялся реальной кнопкой «Попробовать демо», без подмены cookies или клиентского состояния. Использовался встроенный браузер ZCode.

По DOM-состояниям наблюдались:
- Демо-вход: переход `/login` → `/`, показ приватного обзора дома.
- Навигация «Освещение»: переход к карточкам пяти светильников.
- «Включить Прикроватный свет»: `aria-checked` изменился `false` → `true` после ответа API.
- «Яркость · Прикроватный свет»: ArrowRight изменил 70 → 71; управление доступно с клавиатуры.

Снимки: [вход](../gui-test-screenshots/t1-login.png), [обзор](../gui-test-screenshots/t2-dashboard.png), [свет](../gui-test-screenshots/t3-lighting.png), [яркость](../gui-test-screenshots/t4-brightness.png).

Снимки экрана были получены, но **не могли быть визуально просмотрены**, поскольку текущая модель и доступные агенты не поддерживают входные изображения. Поэтому эти результаты — функциональные наблюдения, **не завершённая визуальная приёмка**. Нельзя считать контраст, красоту композиции, обрезку фотографий и качество эффектов подтверждёнными только DOM-геометрией.

После исходного этапа проверка была явно остановлена для исправлений: график климата должен использовать датчик температуры, admin PATCH — только изменённые поля, корректные диапазоны симуляции, размер страницы журнала20 и вложенные диалоги. Затем затронутые действия проверяются повторно.

## Ограничения проверки

- Отдельный браузерный runtime console API в текущем инструменте не предоставлен; консольные ошибки через инъекцию не собирались. Проверялись видимые ошибки, DOM и логи сервера разработки.
- Docker не установлен, контейнерная сборка не запускалась.
- Публикация/HTTPS deployment не выполнялись.
- Аппаратная интеграция не входит в учебный симулятор и не проверялась.
- Фотографии принадлежат авторам референса; до публичного размещения необходима замена лицензированными материалами.
